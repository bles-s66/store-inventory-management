# Система учета товаров магазина

## О проекте

Страница для учета товаров в магазине например электроники.

## Основные блоки страницы

- Хедер с навигацией;
- «Склад» с карточками товаров;
- Поиск;
- «Закупки»;
- «Продажи»;
- Футер

## Как открыть

Скачать проект и открыть файл `index.html`


## Изображения

Пока не используются. В карточках товаров используются эмодзи.

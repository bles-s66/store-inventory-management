# Система учета товаров магазина

## О проекте

Была создана страница для учета товаров в магазине например электроники.

## Блоки страницы

- Хедер с навигацией;
- «Склад» с карточками товаров;
- Поиск;
- «Закупки»;
- «Продажи»;
- Футер

## Как открыть

Скачать проект и открыть файл `index.html`


## Реализация

Изображения пока не используются. В карточках товаров используются эмодзи.
Для создания страницы использовались HTML и CSS. HTML используется для структуры страницы, а css для оформления, отступов, размеров и тд.
